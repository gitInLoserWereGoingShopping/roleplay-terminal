# Roleplay Terminal

A web-based roleplay game that presents as a vintage relay terminal. On first launch, the story begins immediately.

## Run locally

```bash
python -m http.server 5173
```

Open `http://localhost:5173`.

## Controls

- Type `help` for commands
- Use `1`, `2`, `3` or type a choice label
- `f` toggles fullscreen
- `Esc` exits fullscreen
